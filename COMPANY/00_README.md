## 🎯 نظرة عامة | Overview

هذا الفولدر يحتوي على كامل وثائق الورشة منظّمة في 8 أقسام رئيسية + أرشيف. كل قسم بصيغة موحدة: **رقم_عربي - English** ليسهل التصفح والترتيب.

This folder contains all workshop documentation organized in 8 main sections + archive. Each folder follows the unified format: **number_Arabic - English** for easy browsing.

---

## 📁 الأقسام الرئيسية | Main Sections

### `00_فهرس - Index`
الفهارس الشاملة لكل ملفات الورشة (Excel files).
- 📊 Complete File Index — فهرس شامل
- 📊 ORGANIZATION SUMMARY — ملخص التنظيم
- 📋 Index — الفهرس الشامل
- 🗂 Workshop File Index — فهرس الملفات

### `01_الورشة - Workshop`
هوية الورشة الرئيسية، إدارتها، تقاريرها العامة.
- **ادارة الورشة:** خطة العمل، القوانين والأنظمة، الاتفاقيات، الخطط المستقبلية، الأفكار والنقاشات
- **تقارير الورشة العامة:** تقارير شهرية، سنوية، أرشيف
- **هوية الورشة الرئيسية:** القيم والرؤية والرسالة، اللوغو والألوان، صوت البراند

### `02_الأشخاص - People`
ملفات الفريق والشركاء والعاملين.
- **الموظفين:** ملفات شخصية، أداء، تدريب، عقود + سجل الحضور العام
- **الشركاء:** حسين، سجاد نزار، يوسف + اتفاقية مشتاق
- **المستقلين والخارجيين:** نموذج لكل مستقل خارجي

### `03_خطوط الإنتاج - Production Lines`
كل خط إنتاج له فولدر كامل بـ 8 طبقات: استراتيجية، براند، تشغيل، فريق، مالية، قانوني، تقارير، أفكار.
- خط اعادة التدوير
- خط الاعلانات
- خط الذكاء الصناعي
- خط الطابعة
- خط المجتمع
- خط المنتجات (يحتوي على الدليل التأسيسي الشامل)
- خط الهندسي

### `04_مشاريع العملاء - Client Projects`
- **نشط - Active:** ياس 2026، فايبر اكس، تجميل المدينة كرسمس 2026، رمضان 2026 البلدية
- **مقترح - Proposed:** Y4C Project
- **مكتمل - Completed:** مشروع 1971، مشروع MG

### `05_المالية - Finance`
- **الحالي - Active:** قاعدة المالية الرئيسية، المبيعات اليومية، المصروفات والواردات
- **الأرشيف - Archive:** بيانات مالية قديمة، نسخ سابقة

### `06_فولدر التوزيع - Inbox`
صندوق الوارد للملفات الجديدة قبل توزيعها على الأقسام.
- أفكار عامة، تسجيلات صوتية، صور مرجعية، مسودات، نقاشات مسجلة، ملفات غير مصنفة

### `07_المحادثات - Communications`
- **WhatsApp:** محادثات تقارير اليومية، كروب الحضور والخروج، كروب الورشة + كل جهات الاتصال (vCards)

### `_Archive - الأرشيف القديم`
ملفات قديمة، مكررة، أو غير مستخدمة:
- **_Temp & Scripts:** scripts قديمة وملفات backup
- **خطط أعمال قديمة:** نسخ سابقة من خطط الأعمال
- **ملفات مكررة:** نسخ احتياطية
- **ملفات نصية قديمة:** مسودات قديمة

## ⚠️ ملاحظة مهمة | Important Note

يوجد فولدر اسمه `Finance - المالية` فيه ملف واحد محمي (`Workshop_Master_Database_V2.xlsx`) لم نتمكن من نقله لأنه مفتوح في برنامج آخر (الأرجح Excel أو OneDrive sync). 

**للحذف اليدوي:**
1. أغلق Excel وOneDrive sync مؤقتاً
2. الملف موجود فعلاً كنسخة في: `01_الورشة - Workshop/ادارة الورشة/خطة العمل الرئيسية/Workshop_Master_Database_V2.xlsx`
3. احذف الفولدر `Finance - المالية` كاملاً

## 📋 ما تم في عملية التنظيم | Reorganization Summary

✅ **حُذف:** كل ملفات Lock (.~lock.) من LibreOffice
✅ **دُمج:** فولدران مكرران بأسماء `خطوط الإنتاج` و `خطوط الانتاج`
✅ **نُقل:** كل محتويات الفولدرات الإنجليزية القديمة (Attendance, Finance, History & Notes, Inventory, Projects, Regulations & Docs, WhatsApp Chats, _Temp & Scripts) إلى الهيكل العربي الجديد
✅ **حُذفت:** النسخ المكررة (تحققنا بـ MD5 hash)
✅ **رُتبت:** كل ملفات الجذر إلى أقسامها المناسبة
✅ **رُقمت:** الفولدرات بصيغة موحدة `XX_عربي - English`

## 🚀 للتعامل مع هذا الفولدر | Working with this folder

- **للبحث عن ملف:** ابدأ من `00_فهرس - Index`
- **للملفات الجديدة:** ضعها في `06_فولدر التوزيع - Inbox` ثم وزعها لاحقاً
- **للأرشفة:** انقل القديم إلى `_Archive - الأرشيف القديم`
- **عند التعديل على ملف Excel:** أغلقه قبل نقل أو حذف الفولدر
