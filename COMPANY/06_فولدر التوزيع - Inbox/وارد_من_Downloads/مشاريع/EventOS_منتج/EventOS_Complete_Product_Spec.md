## Executive Summary

**EventOS** is an AI-powered event planning and execution platform designed to simplify event management by automating supplier selection, order management, payment processing, and timeline tracking. Unlike traditional event planning tools that require extensive user input, EventOS leverages AI to pre-generate complete event plans with supplier recommendations, allowing users to make minimal decisions.

**Key Promise:**
> "Choose event type, budget, and style. AI builds everything. You just approve and pay."

**Target Market:** Basra, Iraq (expanding to Baghdad, then GCC)

**Primary Users:** Event-planning couples, families, and individuals who want stress-free event management

**Unique Differentiators:**
- Full automation with AI + human concierge hybrid
- Integrated supplier marketplace with in-app ordering
- Visual-first decision-making (minimal typing)
- Own production workshop (CNC/laser/printing capabilities)
- Real-time execution tracking and smart supplier replacement

## Product Overview

### Problem Statement
Event planning in Iraq involves:
- Fragmented supplier ecosystem (no centralized platform)
- High coordination burden across vendors
- Lack of timeline/budget management
- No verification of supplier quality
- Risk of supplier cancellation without backup
- Language barriers in digital tools

**EventOS solves this** by creating a single platform where:
- All suppliers are verified and integrated
- Event plans are auto-generated by AI
- All orders and payments are centralized
- Timelines are automatically tracked
- Suppliers have automatic backups

### Product Feeling
**"This app feels like a personal event manager that builds and executes everything for you."**

**Tone:** Premium + Friendly (not cheap, not overly luxury)
- Clean
- Elegant
- Easy to use
- Trustworthy
- Approachable

## Core Vision & Positioning

### What EventOS Is
An **AI Event Operating System** that:
1. Generates complete event plans automatically
2. Selects verified suppliers for each category
3. Builds unified shopping carts
4. Handles payments securely
5. Tracks execution in real-time
6. Replaces suppliers intelligently if issues arise
7. Provides human concierge support for events > $5,000

### What EventOS Is NOT
- A simple checklist tool
- A vendor directory only
- A manual planning assistant
- A generic marketplace

### Core Principle
**Minimal user thinking. Maximum system automation.**

Users should only:
1. Choose event type
2. Pick style/mood
3. Select budget level
4. Approve AI recommendations
5. Make payment
6. Receive updates

## Feature Breakdown

### Core Features (MVP)

#### 1. Event Template Engine
**Purpose:** Auto-generate complete event plans without user thinking

**Included:**
- Pre-built templates for:
  - Weddings (main focus)
  - Birthdays
  - Engagements
  - Gift orders
  
- Each template includes:
  - Master checklist (30-50 items)
  - Budget split recommendations
  - Quantity calculations based on guest count
  - Supplier categories
  - Timeline defaults
  - Dependency mapping

**Smart Logic:**
```
If event_type == "wedding":
  - Base items: venue, food, drinks, decoration, clothing, services
  - Quantity scaling:
    - Food: guest_count × meal_price
    - Chairs: guest_count + 10%
    - Drinks: guest_count × 1.5 servings
    - Cake: guest_count / 10 (multiple tiers)
  - Budget defaults: 40% venue, 25% food, 10% decoration, 10% clothing, 10% services, 5% other
  - Timeline: 30 days minimum lead time
```

#### 2. AI Planning Agent
**Purpose:** Intelligent decision-making for supplier selection and optimization

**Capabilities:**
- Generate event plans
- Select supplier packages (Basic/Standard/Premium)
- Compare prices and quality
- Detect missing items
- Replace unavailable suppliers
- Budget optimization
- Timeline management
- Send supplier requests

**Decision Trees:**
```
When selecting supplier:
  1. Check style preference
  2. Check budget range
  3. Check availability
  4. Check location (delivery distance)
  5. Check ratings
  6. Recommend top 3 options
  7. Mark "AI Recommended" on best value
  
When supplier unavailable:
  1. Find alternative in same category
  2. Compare price difference
  3. Check timeline impact
  4. Ask user approval: "Supplier X unavailable. 
     Replace with Y? +50,000 IQD"
  5. Auto-replace if user approves
```

### Decision Trees (Deterministic Logic)

#### Package Selection Logic
```
IF budget > normal_budget * 1.5:
  RECOMMEND "premium"
ELSE IF budget > normal_budget * 0.8:
  RECOMMEND "standard" (most profitable)
ELSE:
  RECOMMEND "budget"

WHERE normal_budget = industry_avg[event_type][guest_count]
```

#### Supplier Selection Logic
```
FOR each category:
  candidates = suppliers[category, city, verified==true]
  
  FOR each candidate:
    calculate_score = (
      rating * 0.4 +
      (1 - distance/max_distance) * 0.2 +
      availability_match * 0.2 +
      (budget_fit / candidate_price) * 0.2
    )
  
  top_3 = sorted(candidates, score DESC)[:3]
  
  MARK top_1 as "AI Recommended"
  RETURN [top_1, top_2, top_3]
```

#### Budget Allocation Logic
```
FUNCTION allocate_budget(event_type, guest_count, total_budget):
  
  IF event_type == "wedding":
    splits = {
      venue: 0.40,
      food: 0.25,
      decoration: 0.10,
      clothing: 0.10,
      services: 0.10,
      other: 0.05
    }
  
  ELSE IF event_type == "birthday":
    splits = {
      venue: 0.25,
      food: 0.35,
      decoration: 0.20,
      services: 0.15,
      other: 0.05
    }
  
  RETURN {
    category: total_budget * splits[category]
    FOR EACH category IN splits
  }
```

#### Quantity Calculation Logic
```
FUNCTION calculate_quantity(item_type, guest_count):
  
  IF item_type == "food":
    RETURN guest_count * meal_quantity
  
  ELSE IF item_type == "chairs":
    RETURN guest_count + (guest_count * 0.1)  # 10% extra
  
  ELSE IF item_type == "drinks":
    RETURN guest_count * 1.5  # servings
  
  ELSE IF item_type == "cake":
    RETURN 1 + FLOOR(guest_count / 100)  # tiers
  
  ELSE IF item_type == "flowers":
    tables = CEIL(guest_count / 8)
    RETURN tables  # arrangement per table
  
  DEFAULT: RETURN 1
```

#### Timeline Calculation Logic
```
FUNCTION create_timeline(event_date, items):
  
  FOR each item IN items:
    required_by_date = event_date - item.production_time_days
    
    milestones = [
      {
        date: required_by_date,
        task: "ORDER: " + item.name,
        priority: "high"
      },
      {
        date: required_by_date - 3,
        task: "FINAL CONFIRM: " + item.name,
        priority: "high"
      },
      {
        date: event_date - 1,
        task: "DELIVER: " + item.name,
        priority: "critical"
      }
    ]
    
    ADD milestones TO timeline
  
  SORT timeline BY date
  RETURN timeline
```

#### Supplier Replacement Logic
```
FUNCTION replace_supplier(original_supplier_id, date_needed):
  
  original = get_supplier(original_supplier_id)
  category = original.category
  city = original.location_city
  
  alternatives = search_suppliers(
    category=category,
    city=city,
    available_on=date_needed,
    verified=true,
    exclude_id=original_supplier_id
  )
  
  best_replacement = max(alternatives, key=rating)
  
  price_difference = best_replacement.price - original.price
  
  IF price_difference > 50000:
    RETURN {
      status: "requires_approval",
      message: "Replacement found but +{price_difference} IQD",
      replacement: best_replacement
    }
  
  ELSE:
    RETURN {
      status: "auto_replaced",
      replacement: best_replacement
    }
```

✅ **AI Control:** Auto-select + user approval
✅ **Concierge:** Free at $5000+, paid upgrade for smaller events
✅ **MVP Events:** Wedding, Birthday, Engagement, Gift ordering
✅ **Geography:** Basra first, then Baghdad, then GCC
✅ **User Roles:** Individual users (professional dashboard in Phase 2)
✅ **Notifications:** WhatsApp + Push (SMS later)
✅ **Language:** Arabic (Iraqi dialect) first, English later
✅ **Legal:** Platform-controlled policies
✅ **Workshop:** Featured but not exclusive (you win by quality, not forced)
