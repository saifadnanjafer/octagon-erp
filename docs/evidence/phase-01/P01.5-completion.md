## What was implemented

1. **View Registry** (`platform/kernel/views/index.mjs`)
   - Schema-validated registration of pages, lists, forms, details, workspaces, dialogs, and custom views.
   - Module ownership validation (module must be enabled before registration).
   - Route uniqueness enforcement; a second view cannot claim an owned route.
   - Deterministic menu ordering by `menu_location` and view `id`.
   - Versioned view descriptors with `platform_view_versions` history table.
   - Rollback to any previous descriptor version.
   - Extension patch application with conflict detection (`target` + `op` uniqueness).
   - Action bindings, required permissions, required feature states, and localization keys stored as structured metadata.
   - Arabic localization keys preserved in `localization_keys`.
   - Audit evidence written on register/unregister.
   - Read-only by design: view metadata cannot mutate business invariants.

2. **Migration 004** (`database/migrations/004_platform_kernel_views.mjs`)
   - Creates `platform_view_versions` for descriptor history.
   - Seeds a reference page `kernel_reference_page` with Arabic title (`صفحة المرجع`) at route `/kernel/reference` and menu location `platform:reference`.
   - Records the initial version in `platform_view_versions`.

3. **Reference page** (`kernel_reference_page`)
   - Bound to `product_category` entity.
   - Demonstrates list action binding and menu registration without replacing the existing Octagon shell.

## Risks and decisions

1. **No renderer replacement**: The registry stores descriptors; the existing Octagon shell (`app.js`, `index.html`) remains the active renderer. Phase 07 will consume these descriptors.
2. **Route ownership**: A route is owned by the first registered view. Re-registration requires a version update or explicit `unregister`. This prevents accidental hijacking by disabled modules.
3. **Patch conflict rule**: Patches are identified by `(target, op)`. A duplicate target/op is rejected. Finer-grained merge rules are deferred to Phase 07.
4. **Arabic UX preserved**: The reference page carries `title_ar` and localization keys so the Arabic navigation contract remains intact.
5. **Payroll/Attendance**: No view changes to payroll or attendance pages.
